# Bridging Personalization and Privacy (Chrome Extension)

A Chrome extension and ML pipeline that predicts users’ personality traits and privacy comfort levels from local browsing behavior to enable ethical, trust‑based personalization. It processes history data on‑device and never sends raw URLs to external servers.

---

## Features

- Reads Chrome browsing history for selected periods (7 / 30 / 90 days).
- Extracts behavioral features and predicts personality & privacy level.
- Interactive dashboard with charts for behaviour and risk insights.
- Exports full history plus analysis as CSV files.
- Optional AI‑generated natural‑language insights about habits and privacy.
- Runs locally in the browser for better privacy control.

---

## Tech Stack

- **Frontend / UI:** HTML, CSS, JavaScript, Chart.js  
- **Browser APIs:** Chrome History, Storage, Downloads APIs  
- **Machine Learning (offline):** Python, Scikit‑learn (RandomForest), Pandas, NumPy, Joblib  
- **Tools:** Visual Studio Code, Git, GitHub, Chrome Developer Mode
